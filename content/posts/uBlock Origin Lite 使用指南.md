# uBlock Origin Lite 使用指南

## 一、什么是 uBlock Origin Lite？

uBlock Origin Lite（简称 uBO Lite）是 uBlock Origin 的轻量级版本，是一款**免费、开源、高效**的广告拦截浏览器扩展。

### 主要特点：
- ✅ **轻量级**：占用资源少，运行流畅
- ✅ **高效拦截**：可拦截广告、追踪器、恶意网站等
- ✅ **完全免费**：无付费功能，无白名单交易
- ✅ **开源透明**：代码公开，安全可靠
- ✅ **无需权限**：采用 Manifest V3 架构，权限要求更低

## 二、安装步骤

### 1. Chrome 浏览器
1. 打开 **Chrome 网上应用店**
2. 搜索 `uBlock Origin Lite`
3. 点击"**添加至 Chrome**"
4. 确认安装即可

### 2. Edge 浏览器
1. 打开 **Edge 加载项商店**
2. 搜索 `uBlock Origin Lite`
3. 点击"**获取**"或"**添加到 Edge**"
4. 确认安装

### 3. Firefox 浏览器
1. 打开 **Firefox 附加组件商店**
2. 搜索 `uBlock Origin Lite`
3. 点击"**添加到 Firefox**"
4. 确认安装

> **提示**：如果找不到 Lite 版本，也可以安装完整版的 uBlock Origin，功能更强大。

## 三、基本使用方法

### 1. 启用/禁用拦截
- 点击浏览器右上角的 **uBlock Origin 图标**
- 点击大电源按钮可**临时禁用/启用**当前网站的拦截

### 2. 查看拦截统计
- 打开扩展面板后可以看到：
  - 当前页面拦截的广告数量
  - 拦截的域名数量
  - 节省的流量大小

### 3. 自定义过滤规则
1. 点击 uBlock Origin 图标
2. 点击右下角的**齿轮图标**（打开仪表盘）
3. 进入"**我的过滤规则**"标签页
4. 可以添加自定义规则，例如：
   ```
   ##.ad-banner
   ###popup-dialog
   ||example.com^
   ```

### 4. 添加第三方过滤列表
1. 打开仪表盘（齿轮图标）
2. 进入"**过滤规则列表**"标签页
3. 勾选需要的列表：
   - ✅ **EasyList**：英文广告过滤
   - ✅ **EasyPrivacy**：隐私保护
   - ✅ **CJX's Annoyance List**：中文广告过滤
   - ✅ **AdGuard Chinese**：中文广告过滤
4. 点击"**应用更改**"

## 四、高级功能

### 1. 元素选择器（手动屏蔽网页元素）
1. 点击 uBlock Origin 图标
2. 点击**滴管图标**（元素选择器模式）
3. 鼠标移动到要屏蔽的元素上（会变红）
4. 点击该元素
5. 在弹出的对话框中点击"**创建**"
6. 该元素就会被永久隐藏

### 2. 动态过滤（精细控制请求）
1. 打开仪表盘
2. 进入"**动态过滤**"标签页
3. 可以按域名控制：
   - 脚本（script）
   - 图片（image）
   - Cookie
   - 其他资源

### 3. 拉黑模式（屏蔽特定域名）
1. 在拦截日志中找到不想看到的域名
2. 右键点击该域名
3. 选择"**屏蔽**"即可

### 4. 查看拦截日志
1. 点击 uBlock Origin 图标
2. 点击**列表图标**（打开拦截日志）
3. 可以看到所有被拦截的请求
4. 可以回放查看哪些元素被拦截

## 五、常用场景配置

### 场景 1：视频网站去广告
推荐订阅：
- ✅ EasyList
- ✅ CJX's Annoyance List
- ✅ 自定义规则（针对特定网站）

### 场景 2：保护隐私
推荐订阅：
- ✅ EasyPrivacy
- ✅ AdGuard Tracking Protection
- ✅ 禁用第三方 Cookie

### 场景 3：提升网页加载速度
- 启用图片拦截（谨慎使用）
- 禁用不必要的脚本
- 拦截大型广告资源

### 场景 4：净化新闻网站
- 使用元素选择器移除弹窗
- 屏蔽侧边栏广告
- 移除推荐阅读等干扰元素

## 六、常见问题解答

### Q1: 为什么有些广告拦不住？

**答**：可能原因：
1. 过滤规则未更新 → 点击"**立即更新**"
2. 需要添加针对性的过滤规则
3. 某些是网站自身内容，不是广告

### Q2: 影响网页正常使用怎么办？

**答**：
1. 临时禁用当前网站的拦截（点击电源按钮）
2. 在动态过滤中放行特定资源
3. 将网站加入白名单（不推荐）

### Q3: uBlock Origin 和 uBlock Origin Lite 有什么区别？

**答**：
| 特性 | uBlock Origin | uBlock Origin Lite |
|------|--------------|-------------------|
| 架构 | Manifest V2 | Manifest V3 |
| 性能 | 更强 | 轻量 |
| 权限 | 较多 | 较少 |
| 兼容性 | 部分浏览器 | 新浏览器 |

### Q4: 会拦截正常内容吗？

**答**：偶尔会误杀，可以：
1. 查看拦截日志找到误杀的内容
2. 将该域名加入白名单
3. 或添加例外规则

### Q5: 如何备份我的设置？

**答**：
1. 打开仪表盘
2. 进入"**设置**"标签页
3. 点击"**导出到文件**"
4. 保存配置文件即可

## 七、最佳实践建议

### ✅ 推荐做法：
1. 定期更新过滤规则列表
2. 只订阅必要的过滤列表（避免过多影响性能）
3. 善用元素选择器自定义净化网页
4. 遇到问题先查看拦截日志

### ❌ 避免做法：
1. 不要同时安装多个广告拦截器（可能冲突）
2. 不要随意添加不明来源的过滤规则
3. 不要轻易将网站加入白名单
4. 不要拦截所有图片（会影响正常浏览）
