# 电子证照常见问题解答

本文汇总了电子证照系统和电子签章系统使用过程中的常见问题及解答，帮助用户快速解决操作中遇到的疑问。

## 一、电子证照系统常见问题

### 1. 问：电子证照如何查看一证一接口数据？

**答：** 按照以下步骤操作：

1. **登录系统**：首先打开电子证照系统并登录
2. **进入统计分析**：点击左侧菜单栏的 **"统计分析"**
3. **选择统计类型**：在二级菜单栏选择 **"一证一接口调用统计"**
![点击按钮](/images/dzzz/统计分析.png)
4. **查看数据**：在右侧即可看见各个区划下的调用次数
5. **查看详情**：在右侧点击 **"查看"** 按钮，即可查看：
   - 事项名称
   - 证照类型
   - 调用部门
   - 各个证照的调用次数

**操作要点：**
- 支持按时间范围筛选数据
- 可以导出Excel格式的统计报表
- 数据实时更新，反映最新的调用情况

### 2. 问：如何查看电子证照的汇聚量和签章率？

**答：** 参考《Excel 2024 Power Query 实战：自动获取并处理电子证照统计数据》文章，通过API接口自动获取以下数据：
- 区划名称
- 证照类型汇聚数
- 录入量
- 已签章数
- 未签章数
- 签章率

## 二、电子签章系统常见问题

### 1. 问：电子签章如何查看签章信息？

**答：** 按照以下步骤操作：

1. **登录系统**：首先登录统一电子印章系统
2. **选择印章类型**：选择 **"行政审批和公共服务章"**，然后点击 **"确定"**
3. **进入印章管理**：进入系统后，点击左侧菜单栏的 **"印章管理"**
4. **搜索印章**：在右上角搜索框中，可以根据以下信息进行搜索：
   - 印章名称
   - 制章单位
   - 印章类型
   - 应用范围
   - 生效时间
   - 截止时间
   - 印章关系
   - 制作时间
   - 绑定编号
   - 与国办对接状态
5. **查看详情**：输入搜索条件后点击回车，下方就会显示对应的印章详细信息

**操作要点：**
- 支持多条件组合搜索
- 可以查看印章的完整生命周期信息
- 支持印章状态的实时监控

### 2. 问：电子签章申请流程是什么？

**答：** 标准申请流程如下：

1. **提交申请**：向当地政数局提交印章申请表单以及空白印章信息
2. **印章制作**：审核通过后，系统自动生成电子印章
3. **印章绑定**：将印章与相关业务系统或用户绑定
4. **印章启用**：完成绑定后，印章即可正常使用

## 三、常见问题排查

### 1. 接口调用失败怎么办？

**可能原因及解决方案：**
- **网络问题**：检查网络连接是否正常
- **权限问题**：确认当前账号有接口调用权限
- **参数错误**：检查接口参数是否正确
- **系统维护**：确认系统是否在维护时段

### 2. 数据不显示或显示异常？

**排查步骤：**
1. 检查筛选条件是否正确
2. 确认数据更新时间
3. 查看系统公告是否有相关说明
4. 联系当地政数局

### 3. 印章无法正常使用？

**常见原因：**
- 印章已过期
- 印章权限不足
- 系统兼容性问题
- 浏览器缓存问题

### 4. 问：签章时出现白色条框，无法完成签章是什么情况？

**答：** 这是浏览器兼容性问题导致的。请按照以下步骤解决：

1. **更换浏览器**：使用 **360安全浏览器**
2. **切换模式**：在360安全浏览器中切换到 **兼容模式**
3. **操作步骤**：
   - 打开360安全浏览器
   - 在地址栏右侧找到模式切换按钮（通常显示为"闪电"图标或"e"图标）
   - 点击切换为 **兼容模式**（显示为"e"图标）
   - 重新访问电子签章系统进行签章操作

**原因分析：**
- 电子签章系统对浏览器内核有特定要求
- 现代浏览器（如Chrome、Edge等）的极速模式可能不兼容某些ActiveX控件或插件
- 360安全浏览器的兼容模式使用IE内核，能更好地支持传统政务系统

**备用方案：**
- 如果360安全浏览器仍无法解决，可尝试使用 **Internet Explorer 11**
- 确保浏览器已启用ActiveX控件和相关插件
- 清除浏览器缓存后重试
