## 数据库对比工具使用

对比工具位于117服务器上。

### 常见错误处理

如果执行对比时出现以下错误：

```
Caused by: java.sql.SQLException: ORA-00604: 递归 SQL 级别 1 出现错误
ORA-01000: 超出打开游标的最大数
ORA-00604: 递归 SQL 级别 1 出现错误
ORA-01000: 超出打开游标的最大数
ORA-01000: 超出打开游标的最大数
```

请按以下步骤处理：

1. 首先在数据库中执行查询当前游标最大数：
```sql
SELECT * FROM V$PARAMETER WHERE NAME = 'open_cursors';
```

2. 然后执行修改游标数命令（将*****替换为更大的数值）：
```sql
ALTER SYSTEM SET open_cursors = ***** SCOPE=BOTH;
```

3. 重新同步数据库
4. 同步完成后，记得将游标数改回原值

**注意**：请严格按照上述顺序执行操作。

## 数据库密码过期处理

### 问题描述
数据库密码过期导致无法连接。

### 解决方法
执行以下命令（需要修改为对应库的用户名）：

```sql
-- 修改密码
ALTER USER 库名 identified by 密码;

-- 解锁账户
ALTER USER SXGL_INIT ACCOUNT UNLOCK;
```

## 查询数据库空间占用

### 查询指定用户的数据库大小

此 SQL 用于查询 Oracle 数据库中指定用户（schema）的总大小、数据大小和索引大小。

```sql
SELECT 
  '库名' AS 数据库名,
  ROUND(SUM(bytes) / 1024 / 1024, 2) AS "总大小(MB)",
  ROUND(SUM(CASE WHEN segment_type = 'TABLE' THEN bytes ELSE 0 END) / 1024 / 1024, 2) AS "数据大小(MB)",
  ROUND(SUM(CASE WHEN segment_type = 'INDEX' THEN bytes ELSE 0 END) / 1024 / 1024, 2) AS "索引大小(MB)"
FROM 
  dba_segments 
WHERE 
  owner = '库名'  
  AND segment_type IN ('TABLE', 'INDEX');
```

**说明**：
- `owner = '库名'`：指定要查询的用户名（可替换为其他用户）
- `总大小(MB)`：该用户所有表和索引占用的总空间
- `数据大小(MB)`：所有表占用的空间
- `索引大小(MB)`：所有索引占用的空间
- `ROUND(..., 2)`：结果保留两位小数

**使用场景**：
- 监控数据库空间使用情况
- 评估数据增长趋势
- 优化存储空间分配
