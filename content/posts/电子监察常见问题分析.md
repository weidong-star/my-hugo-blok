# 电子监察常见问题分析

> 电子监察系统本身不会留存办件，监察办件均为综窗办件。本文详细介绍了电子监察系统的监察项、监察规则以及超期办件的处理方法。

## ⚙️ 二、监察规则

### 1. 办理时效

#### （1）业务预警（办理中）
  - **状态**：在用
  - **类型**：黄牌
  - **规则说明**：
  - 即办件：6小时 ≤ 办理时间 ≤ 8小时
  - 承诺件：
    1. 承诺时间 > 5天：承诺时限 - 3天 ≤ 办理时间 ≤ 承诺时限
    2. 承诺时间 ≤ 5天：承诺时限 × 50% ≤ 办理时间 ≤ 承诺时限

  - **判断逻辑**：
```sql
-- 即办件
6 <= 系统当前时间 - 受理表.办理时间 <= 8小时

-- 承诺件（大于5天）
0天 < 受理表.承诺时间 - 系统当前时间 <= 3天

-- 承诺件（小于等于5天）
受理表.承诺时限/2 <= 系统当前时间 <= 受理表.承诺时限
```

#### （2）环节超时(办理中)
  - **状态**：在用
  - **类型**：红牌
  - **规则说明**：
  - 即办件：办理时间 > 承诺办理时限
  - 承诺件：办理时间 > 承诺办理时限

  - **判断逻辑**：
```sql
-- 即办件和承诺件
0天 >= 受理表.承诺时间 - 系统当前时间
```

#### （3）环节超时(业务办结)
  - **状态**：在用
  - **类型**：红牌
  - **规则说明**：环节结束时间 > 环节承诺时间

  - **判断逻辑**：
```sql
0天 >= 环节结束时间 - 环节承诺时间
```

#### （4）业务超时(办理中)
  - **状态**：在用
  - **类型**：红牌
  - **规则说明**：当前时间 > 承诺办理时间

  - **判断逻辑**：
```sql
0天 >= 受理表.承诺时间 - 系统当前时间
```

#### （5）业务超时办结
  - **状态**：在用
  - **类型**：红牌
  - **规则说明**：办结业务中 办理时间 > 承诺办理时间

  - **判断逻辑**：
```sql
办结表.办结时间 > 受理表.承诺时限
```

## 🚨 三、超期办件处理

> **重要说明**：因电子监察系统监察的超期办件是来源于综窗，所以不管自建系统是否已进行了办结，都以综窗为准。

### 1. 综窗显示未办结

#### （1）核实自建系统办件状态
如已办结，综窗仍然显示未办结，排查如下：

  - **使用卓繁的乌兰察布市行政审批系统**
  - 系统地址：[乌兰察布政务审批系统](http://10.25.243.124:8081/zwpt/login.do)
  - 联系技术支持：刘鸿博
  <!-- （18548018188） -->

  - **使用区建系统（如民政局、人社局等）**
  - 联系对应厅级部门系统技术支持

#### （2）如自建系统未办结
  - 督促对应办理人员尽快进行办结操作

### 2. 综窗显示已办结

如综窗显示已办结，而电子监察仍然显示未办结，请按以下步骤处理：

1. **整理问题办件信息**
   - 办件编号
   - 办件名称

2. **将整理好的Excel文档发送至《全区电子监察沟通群》**

3. **@杨志华老师进行排查**

> ⚠️ **注意**：发送时请说明"此办件为综窗已办结，电子监察仍显示未办结"。
