## 概述

本文档详细介绍了排队叫号（好差评）系统的操作流程和功能按钮说明，旨在帮助窗口工作人员快速掌握系统使用方法，提高服务效率。

## 系统登录

### 登录流程

1. 打开软件后，系统会自动跳转到用户登录界面
2. 输入管理员分配的账号、密码及验证码
3. 点击登录按钮进入系统

![登录界面](/images/czsc/pdjh/用户登录.png)

### 评价器状态

**未登录状态**：评价器在呼叫器未登录时，界面不显示姓名和工号信息

![评价未登录界面](/images/czsc/pdjh/评价未登录.png)

**已登录状态**：登录成功后，评价器界面将显示工作人员姓名和工号等信息

![评价已登录界面](/images/czsc/pdjh/评价已登录.png)

## 呼叫界面功能说明

登录呼叫界面后，系统会显示排队信息和操作按钮。主界面如下：

![呼叫页面](/images/czsc/pdjh/呼叫页面.png)

### 功能按钮说明

| 按钮名称 | 功能描述 |
|---------|---------|
| 呼叫 | 叫号后，通过此按钮将办理本窗口业务的群众叫到窗口 |
| 重呼 | 当群众未注意到呼叫时，可点击重呼再次发送提醒短信 |
| 选择事项 | 呼叫群众后，选择其办理的具体事项。可从推荐、收藏或全部事项中选择 |
| 转办 | 将当前群众转至其他窗口办理（使用频率较低） |
| 完成 | 事项办理完毕后，点击完成结束当前业务流程 |
| 特护 | 对于已办完业务但临时有事的群众，可重新呼叫之前的号码 |
| 切换业务 | 为已选择的号码重新切换办理业务类型 |
| 弃号 | 多次呼叫群众仍未到场时，可点击弃号处理 |
| 暂停业务 | 临时离开窗口时，可暂停业务以防系统自动呼叫 |

## 常见操作流程

### 1. 呼叫群众

点击【呼叫】按钮后，系统将显示申请人的详细信息：

![呼叫后](/images/czsc/pdjh/呼叫后.png)

### 2. 选择办理事项

点击【选择事项】按钮，从系统中选择群众需要办理的具体事项：

![选择事项](/images/czsc/pdjh/选择事项.png)

选择完成后，系统将显示所选事项的详细信息：

![选择完成](/images/czsc/pdjh/选择完成.png)

### 3. 完成业务办理

业务办理完成后，点击【完成】按钮，评价窗口将弹出评价页面，引导群众进行服务评价。

## 注意事项

1. 暂停业务后，请记得恢复业务，避免影响正常叫号
2. 对于特殊情况，可使用特护功能，但请勿频繁使用
3. 选择事项时，如未找到相应业务，可通过搜索功能快速定位
