# 链条系统常见问题汇总

> 本文整理了链条系统在使用过程中的常见问题及其解决方案，主要涉及进度查询、数据同步等方面的问题处理。

## 1. 蒙速办一件事办件进度查询

### 问题描述
如何查询群众在蒙速办提交的办件进度？

### 解决步骤
1. 进入链条系统
2. 保存流水号
3. 在 `ENTERPRISE_ACCEPT` 表中使用流水号查询数据ID
4. 使用查询到的ID作为 `bizId` 调用链条的办件状态查询接口


## 2. 材料更新同步问题

### 问题描述
数据交换系统调度至前置库，由前置库同步到本地事项库后，材料未更新。

### 解决步骤
1. 检查日志表 `ITEM_EXCHANGE_RECORD`
2. 搜索对应事项编码
3. 删除版本记录
4. 重新下发并同步版本

---

## 3. 情形相关事项材料不返回

### 问题描述
更新情形相关的事项时，链条接口不返回材料信息。

### 解决步骤
1. 进入链条系统的"系统管理→事项情形配置"
2. 找到对应事项情形
3. 删除情形及材料信息
4. 重新录入相关信息
5. 进入"系统管理→应用业务配置"
6. 搜索配置项 `enterprise.syncitem.switch`（更新事项ID定时任务）
7. 将配置项修改为 `on`
8. 等待约30分钟后重新调用接口


## 4. 办件材料显示异常

### 问题描述
第一天提交的办件材料在第二天无法查看或显示为空。

### 解决步骤
1. 打开链条库，执行以下SQL查询：

```sql
SELECT item_code, item_id 
FROM ENTERPRISE_ITEM_EXT 
WHERE item_type = '1'
```

2. 如果发现存在值为空的记录，需要修改以下配置项为 `on`：
   - `enterprise.syncitem.switch`
   - `app.itemchange.resourceobject`
   - `app.itemchange.resourceshare`

3. 等待2-3小时后，材料信息将自动恢复

## 📋 注意事项

> ⚠️ **重要提醒**：
  - 进行配置修改前，建议先记录原有配置值
  - 执行SQL查询时注意数据库环境
  - 修改配置后需要留出足够的同步时间
